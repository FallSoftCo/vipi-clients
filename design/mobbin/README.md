# Vipi design references

The private library covers 49 Vipi journeys with 233 distinct full-resolution screens and 18 complete flows. The collection is available to the owner and teammates. [Mobbin collection](https://mobbin.com/collections/c5a5bb7e-8d36-41e2-92e3-12605fc17cc6/mobile/screens?utm_source=codex&utm_medium=ai-assistant&utm_source_platform=mcp) · [Offline image browser](/home/ai/Development/vipi-design-references/index.html) · [Source and image checksums](catalog.json)

Use the relevant screens when changing either client. Open the originals, compare the equivalent state on iOS and Android, and keep a native capture for the behavior under review. For a new feature, search Mobbin for its normal, empty, error, recovery and permission states as applicable. Add visually checked matches to this collection and index. Record an adjacent pattern or an uncovered behavior when a direct match is unavailable.

The native Mac has the same private offline library at `/Users/Apple/Development/vipi-design-references/index.html`.

The connected Mobbin search currently provides iOS and web results. These product examples inform Android design too. Capture Android itself to verify system controls, permission prompts, keyboard behavior and layout. Keep third-party images in the private reference library.

When you add a feature, update the feature entries in [catalog.json](catalog.json) with the source IDs and ordered flow steps. Save the original images and their thumbnails to the private library. To place a native capture beside the matching feature, add its path and a descriptive label to the library’s `vipi/examples.json`. Rebuild the offline browser with `python3 design/mobbin/build_gallery.py /home/ai/Development/vipi-design-references`. The builder verifies image hashes and the local paths before writing the index.

### First-reply notification invitation

Mobbin’s settings flows show how people return to notification controls later. For the initial invitation, use the first successful local send as the moment a reply becomes relevant. Keep the composer available, allow dismissal and open the system prompt only after the person asks for notifications. Compare the real keyboard and permission transitions on both platforms. [Built for Mars · Asking for notifications well](https://builtformars.com/ux-bites/asking-for-notifications-well) · [Built for Mars · Turn on notifications](https://builtformars.com/ux-bites/turn-on-notifications)

### Chats list

Use a real conversation to judge each row. Check a friend with unread messages, a long name, an outgoing message, and a message still waiting for a local translation. Keep the latest message readable, preserve its place when returning from the conversation, and make the empty screen lead directly into finding or inviting a friend. Recheck the name, time and unread count at large text sizes. [WhatsApp inbox](https://mobbin.com/screens/f5304ab1-cd5e-4c68-b363-3900431ca4a5) · [Signal inbox](https://mobbin.com/screens/ec829d11-10b1-404b-8dea-ba563fdcbc36) · [Built for Mars · A useful empty state](https://builtformars.com/ux-bites/a-useful-empty-state)
