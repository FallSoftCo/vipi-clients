# Certified Zucker Free · Pull the plug

FallSoft’s own privacy mark turns a sugar cube into an unplugged two-pin plug. The face carries the complete name in hand-drawn slab capitals. The cut-crystal planes, folded brass blades, coiled lead and raised paper edge were drawn specifically for this edition.

Place the mark where the product’s published practices support the claim, including that FallSoft does not sell the user’s data. Pair it with the applicable privacy policy. Where the issuer is unclear, use “Certified Zucker Free, FallSoft’s privacy mark.”

| Placement | Choose | Size |
|---|---|---|
| A notebook sticker, package or spacious footer | Full light or dark plug | Start at 160 CSS px wide on screen. Proof a physical print at its intended size. |
| A compact footer or byline | Light or dark compact lockup, with outlined lettering alongside the pictogram | 96 CSS px wide or larger |
| An inline icon beside the full written name | Micro plug with the cut Z on its face | 48 CSS px wide. Keep “Certified Zucker Free” immediately adjacent. |
| A one-color print | One-ink plug | Dark ink on a light substrate. Interior cutouts show the substrate color. |

Use the light full sticker on pale and mixed surfaces. The dark version has a wider cream edge for separation. For the compact lockups, choose the version whose lettering contrasts with its surface. The full and compact SVGs have individual outlined letters and named drawing groups. All PNGs are transparent outside the art. The full PNGs and micro icon measure 1280 × 896 pixels. Compact PNGs measure 792 × 304 pixels.

For an informative image use “Certified Zucker Free, FallSoft’s privacy mark” as its accessible name. If visible adjacent text already gives the name and meaning, use an empty alt for the icon.
