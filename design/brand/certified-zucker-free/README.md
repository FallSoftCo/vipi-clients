# Certified Zucker Free

**Certified Zucker Free** is FallSoft’s own privacy mark. Use it where FallSoft can substantiate the product’s public privacy commitments, including that it does not sell users’ data. The crimped sugar packet, cut cube and hand-drawn lettering give the mark its shared identity across products.

## Placing the stamp

- Pair it with a specific plain-language statement and a link to the applicable privacy policy. Suitable copy where supported is “We don’t sell your data.” Identify FallSoft as the issuer wherever that is unclear.
- Use the plum and russet **light** artwork on pale surfaces, or the cream and apricot **dark** artwork on deep surfaces. The **one-ink** artwork is solid near-black and can take a single spot ink for print.
- Start at **96 CSS pixels** wide. All three masters include transparent exterior space. Keep surrounding type or rules at least one capital-letter height from the packet edge, using the C in CERTIFIED for scale.
- Preserve the packet’s tilt, proportions and lettering. For an informative image, use the accessible name “Certified Zucker Free, FallSoft’s privacy mark.” When adjacent text already communicates the same message, use an empty image alt.
- The editable SVGs contain individual named letter paths, a packet outline and cube details. There are no font dependencies. Matching transparent PNGs are 1000 × 680 pixels.
