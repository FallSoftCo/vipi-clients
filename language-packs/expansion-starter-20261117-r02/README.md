# Indonesian, Dutch and Russian starter — guarded r02

This inactive revision retains r01's six English-to/from candidate packs, 18 patterns and three dictionary-backed senses but adds the existing `clause_or_end` right-boundary guard to each local context. Original r01 and its 15-case receipt remain alongside it. r01's `drink coffee` could match `drink coffee grounds`, `drink tea` could match `drink tea tree oil`, and `read the book` could match `read the book jacket`; those noun-modifier cases are not granted by r02. This is an intentionally conservative correction, not proof that all possible ambiguities are eliminated.

The original 15-case holdout was evaluated unchanged against r02; `prior-holdout-result.json` records 9/15 matching previous expectations, six lost emissions and zero emitted outputs. In particular `I drink coffee after lunch.` now abstains. The separately authored 16-case r02 diagnostic records 6 example emissions and 10 expected abstentions including the new adversarial cases and ordinary misses. Examples: `At breakfast I drink kopi.`, `Tonight we are reading the boek.`, `At home I drink чай.` with reading `chay`, and `Сегодня я пью tea.` The evaluator is a Python approximation, not actual native output. The cases are small, authored and not a population accuracy/coverage estimate.

Run `python3 build.py` and `python3 evaluate.py` to reproduce. Packs retain existing source-frame field shapes but empty approval hashes and `source_only_permission: false`; current native language whitelists also exclude these codes. The case-sensitive guard is finite and does not infer stems, new case forms or aliases. See r01 `seeds.json`/README for per-concept CC BY-SA Wiktionary attribution and original reading provenance; r02 retains the same evidence. `prior-holdout.json` and its result are preserved for transparency. Native platform masks, compound geometry, phonetic usefulness and real TTS are not established. The host eSpeak compiler receipt is in r01; generated data is outside the repository.
