# Android 1.0.3 (4) candidate

Source revision `4cc7f95c18e7284e37d4b0505eb771875d0a8c0d` adds the Android sign-in expiry explanation and version increment to the v3 source. Both signed artifacts use the existing upload certificate. Static checks covered the full asset inventory against v3, the compiled expiry text in all 13 resource variants, APK/AAB native library correspondence, the retained libsignal owner class and 16 KiB arm64 ELF alignment. Twenty native libraries match v3 exactly; the eight language and speech libraries were rebuilt from unchanged source and differ in bytes. Device execution and upload are separate qualification steps.

To recover capacity without losing the stopped isolated 5622 emulator, its 23 files were copied to a private retained Storage Box location and both original and retained files were independently SHA-256 verified. Only the large local userdata image was retired; an explicit cold-routing notice remains with its metadata. The separate shared and fresh emulators were not removed. The first two bundle attempts failed before producing artifacts; the third completed under a 5 GiB growth guard and the existing 4 GiB floor. Qualified temporary build intermediates were retired after preserving the artifacts, mapping and receipts.
