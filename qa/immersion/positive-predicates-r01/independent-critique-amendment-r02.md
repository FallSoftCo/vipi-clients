# Addendum: preference versus discourse-like; enjoyment versus benefit

The nine-unit review remains frozen. This addendum narrows the **proposed diagnostic admission**, not the meanings or targets.

**Discourse-like is a material risk.** In “I like totally forgot” and “I like ran away”, `like` can be a filler, not a preference predicate. In “I like, hate this”, substituting ninapenda can introduce liking into an expression of hatred. Person/tense correctness cannot rescue the wrong predicate sense. Rejecting only modal auxiliaries is insufficient.

**Enjoying a legal benefit is a separate sense risk.** “I enjoy diplomatic immunity” can simply assert possession of protection, without asserting pleasure. Ninafurahia can suggest taking pleasure in it. Retained ordinary-pleasure evidence does not establish equivalence here. This is a potential material addition of attitude, not missing Swahili object agreement. No new target or automatic alternate should be generated.

## Smallest bounded candidate contract

Keep the two-word focus, but require a positive following context across actual whitespace, and retain that context in the permission proof:

- **I like:** initially allow `to` or an exact, frozen set of ordinary activity heads / concrete nominal heads already present in retained exposed evidence. Examples for authored testing are `music`, `dogs`, `coffee`, `swimming`, `reading`, `cooking`, `playing`, `watching`. A determiner **alone is not enough**: “I like the other day forgot…” can still contain discourse-like. If the determiner branch is included, require an immediately following member of the same finite nominal-head set (`I like my dog`, `I like the music`). Do not scan arbitrarily far for a noun or add suffix/POS guessing. `to` is a useful bounded preference cue, not a general syntactic proof.
- **I enjoy:** initially allow only a frozen ordinary activity-head set, such as `watching`, `cooking`, `reading`, `swimming`, `singing`, `dancing`, `playing`. The prior exercised enjoyment output supports watching; cooking was an earlier authored contrast. The other heads are proposed authored test contexts, **not previously attested full bilingual clauses or automatically approved outputs**. Do not accept arbitrary `-ing` words, nominal benefits, or `myself`.

The exact finite sets should be declared once before outputs, backed by the retained context or an explicitly authored control. They are transparent context permissions, not a claim to recognize every valid preference/enjoyment. The first diagnostic may be even smaller (e.g. enjoyment watching/cooking); no need to enlarge the set merely to improve a result.

Whitespace must be nonempty and uninterrupted by punctuation or protected ranges. Thus `I like, hate this` cannot borrow `hate` as context. Match complete native words (`reading_room.txt` is not reading); preserve all existing literal/name/enclosing protections. Recognition/mask covers the ambiguous two-word focus even when the context is absent, so withholding cannot silently rescue a weaker liking output. Keep source complements unchanged and count only the two displayed native words toward output depth, not all context words.
