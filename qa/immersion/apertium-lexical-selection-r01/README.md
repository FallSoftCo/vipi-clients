This research comparison executes the already retained English→Spanish bilingual dictionary and lexical-selection component on the same 781 explicit held-out source-focus records as the preceding NB experiment. That benchmark is now exposed. It compares the first bilingual reading before LRX with the first selected/reordered reading after LRX; it does not credit a better bilingual default to contextual selection.

The prefix follows the retained `eng-spa.mode`: normal tagging, pretransfer, source-side genitive rewrite, bilingual lookup, then lexical selection. Stored surface-preserving tag streams are reused only after exact normal-tagger byte parity on the 16 development messages. The run stops before bilingual structural transfer, interchunk, postchunk and generation. New prefix bytes and rule traces are retained.

Mapping is deliberately conservative. Every source lexical-unit analysis must preserve its index through the entire prefix; source headers must remain identical in both bilingual streams. Exact original UTF16 focus spans and occurrence identity are required. Any split/rewrite makes the message untraceable for this experiment; this is a mapping limitation, not evidence the engine cannot process it. No first-word or repeated-lemma alignment is inferred.

The selected noun lemma/number must map uniquely to an exact previously supported training face under the unchanged source/target form, term, number, role, alignment, name and compound policies. All original alternative analyses survive. Unavailable analyses, ambiguous compatible faces, off-training-pool retained evidence and new/unsupported lexical candidates are reported separately; no surface is invented or generated.

`run.py qualify` verifies the existing 16 development messages. Only successful exact qualification permits `run.py cohort`; it reuses their prefix outputs. One CPU, 1 GiB address limit, 300 seconds per stage, 64 MiB aggregate output, 128 MiB reservation and the 8 GiB disk floor are enforced. No downloads, model training, native app change or catalog activation occurs.

The primary [lexical-selection module contract](https://wiki.apertium.org/wiki/Constraint-based_lexical_selection_module) places LRX after bilingual lookup and before transfer. In the pinned [v0.4.2 source](https://raw.githubusercontent.com/apertium/apertium-lex-tools/v0.4.2/src/lrx_proc.cc), `-m` is a deprecated no-op, not evidence of a separate maximum-entropy mode; `-t` records rule firings. The retained manpages and mode are authoritative for actual command arguments. [Stream format](https://wiki.apertium.org/wiki/Apertium_stream_format) distinguishes surface fields, chosen lexical readings and bilingual alternatives.

Method-blind review is independent **agent** review, not native-speaker/customer validation. Full original source messages receive only the exact focus substitution; unchanged/null output receives zero immersion credit. The previous 16 reviewed components and all earlier exposed components are excluded from the new review sample.
