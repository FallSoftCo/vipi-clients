# Reference-priority routing amendment

The original capture and both frozen reviews remain unchanged. This amendment changes only the injected test provider's route composition; the direct adapter, loaders, selection, masks, seed records, permissions, 656 cases/states/densities and existing translation/reference APIs are unchanged.

The new wrapper calls the exact existing BundledImmersionCatalog.reference API for the original source and current source/target pair. That API includes the existing sentence-composed-reference behavior. On a reference hit, it returns the original baseline partial and recognition records unchanged, with only the provider envelope identity rebound. On a miss, it returns the original frame adapter result, likewise rebound. Its identity adds `:reference-first-v1`. No candidate mask is ignored after creation: frame evidence is not considered in the higher-priority reference branch. The core pipeline remains unchanged and continues not to invoke forward source evidence on reverse-language input. The frozen cases are forward EN inputs, so this is a preserved-code boundary, not newly measured reverse qualification.

Each platform consumes its own original captured rows as comparison evidence. Every baseline/direct candidate evidence object and original trace must match the first capture. Every current baseline route must match the original baseline route. On a reference hit, candidate route must exactly equal same-run baseline; on a miss, candidate route must equal its original candidate route. These are hard assertions before a completion receipt. The original protection, all-known, cap and native geometry controls also rerun. No new grid or source cases are introduced.

Timing uses native monotonic clocks around the existing direct adapter call and existing engine result calls. It separately records engine setup, reference-catalog constructor and lookup milliseconds, and the first lookup of each pair/state. Each row/arm still constructs a fresh ConversationImmersion engine as in the original harness; later calls are not claims of warm production-engine cache latency. Shared provider/reference-index first calls and later calls can be reported separately. No extra timing repeats, model calls or inference are added; no total RSS claim will be inferred from these intervals.

The two predecessor outputs add 4–5 MB of immutable comparison evidence to native-inputs-r03. All previous input files remain byte-identical; only the shared manifest gains predecessor hashes. The same 300-second harness body, 600-second instrumentation, 1,200-second owned Android capture, 32 MiB raw output limit, measured APK/DEX reservation and 8 GiB floor remain. Android successor stage writes only the new androidTest harness into the owned private tree. Root owns Apple staging/build/capture. No canonical runtime mutation, activation, source permission promotion, semantic label revision or mask relaxation is authorized by this amendment.
