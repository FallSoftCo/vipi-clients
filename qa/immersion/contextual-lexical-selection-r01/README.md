This isolated research comparison reuses the completed Apertium corpus evidence. It compares component-weighted default target-face frequency with two fixed multinomial naive Bayes estimators: local ±2 token/lemma context and full-sentence token/lemma context. It does not execute Apertium lexical rules or change a client/catalog.

`protocol.json` and `compare.py` were frozen before preparation/prediction. The `prepare` stage binds the existing 313 MB evidence database, original 40k pair manifest and review-exposure sources; it freezes a component split before `compare` fits or predicts. `check_identity.py` is the additional read-only prerequisite requested by independent review: it checks normalized source text across all splits, including different source IDs. Original protocol/split remain unchanged.

Both stages run only on `fallsoft-production-20261106`, one CPU, 1 GiB address space, at most 300 seconds each. Outputs remain in `/srv/fallsoft/staging/vipi-contextual-lexical-selection-20261109-r01`; local small review evidence is under `/home/ai/Development/investigations/vipi-contextual-lexical-selection-20261109-r01`. The complete dataset is retained remotely, with every eligible target alternative and references to immutable original relation/form evidence.

Explicit links and unresolved direct-English candidates are separate pools. Training votes are deduplicated by original source-focus occurrence, divided across conflicting faces and normalized to total component weight one per source spelling/number key. Source/target form, number, term, role, alignment, compound and name restrictions remain visible. Corpus role evidence describes the training occurrence; a later user-facing experiment would still need the live current-source role/scope policy.

The frozen packet presents one exact lexical-focus substitution in each complete original source message. It is not a new native-chat projection or a full Spanish translation. Methods and metrics are separate from the anonymous packet. Parallel-target agreement is a surrogate that can penalize legitimate synonyms; it is not semantic accuracy.
