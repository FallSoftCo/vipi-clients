Keep this comparison non-activated. It demonstrates useful depth and diversity beyond one-unit selection, but not new message coverage, and it exposes one existing content imprecision more often. A subsequent selection/content decision should account for that tradeoff rather than optimize raw token counts. The familiarity proposal in PLAN keeps explicit familiarity separate from exclusions and affects only an already-qualified selected span's presentation. No user action, persistence, scheduler or inferred mastery was implemented. Vipi physical iPad work is excluded under the owner's current directive; no further native job is queued here.
