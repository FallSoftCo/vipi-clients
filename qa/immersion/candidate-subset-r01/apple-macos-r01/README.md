# Seven-message Mac whole-unit experiment

This isolated Mac run used 25 complete noun/verb units from actual retained NLTagger annotations over seven already-exposed authored English messages. The input, installed model availability, Apple Translation harness source and binary were pinned in `preflight.json` before the run. Every isolated output and the contextual translation are retained in `result.json`; `author-review.json` assesses all 25 without claiming independent bilingual gold. The comparison preserves the separate actual Android OpenNLP results and the one POS disagreement.

The Apple Translation harness reports `network_disabled:false`. Models reported installed and no download was requested, but this run is **not network-off isolation evidence**. This is an exposed, small development sample, not population coverage, native iOS validation or permission to activate generated automatic translation. Native name protection and original word-geometry admission were not exercised by this Translation harness. The separate Mac `JapaneseFullReading` check in `reading-result.json` tested three actual Japanese outputs; it does not measure speech or Arabic readings.
