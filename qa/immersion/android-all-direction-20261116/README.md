# Android active-catalog offline qualification

On the dedicated emulator-5620, the active 007 catalog was evaluated with 330 concept-informed authored probes across 110 directions. Both automatic and direct outputs appeared for 131 probes across 79 directions. The independent detector report records all 330 detections and diagnostic geometry for nine Arabic, Chinese, and Korean examples. These are narrow authored probes and do not measure population accuracy.

The offline speech matrix rendered all 110 directed language pairs, including Swahili, and the floor run synthesized actual emitted words for all eleven target voices. Audio generation does not establish listening quality or pronunciation correctness. Private state matched before and after the offline run; Wi-Fi and mobile settings were restored. Detector execution did not separately snapshot private state.
