# Plain-language interface review

Vipi now opens with “Chat with friends. Learn new words.” Onboarding shows the
actual two-language word-switching example and explains the unchanged message
order/grammar. Controls distinguish Word switching, Original message and Full
translation. Downloads clearly serve optional full-message translation. Reading
guides use Latin letters; Listen teaches pronunciation. Bot mini remains a
separate plan with provider and automated-reply disclosure.

Both native builds passed with the frozen source manifest. The iOS component
window check passed light/dark, largest text, step-scroll reset and six automatic
flips with stable height. Android actual onboarding passed font scales 1 and 2,
reachable consent controls, six stable flips, pause/resume/original and four
prepared non-Latin preview controls. Device settings and preferences were
restored; the owned Android emulator was shut down.

This pass does not qualify real purchases, sign-in, provider delivery, acoustic
pronunciation, new conversational coverage or signed Apple persistence. It does
not establish store readiness. Store names/copy remain drafts until saved in the
correct company consoles. Native behavior, consent terms, stored pace values and
accessibility identifiers were preserved; UI-test literal labels were updated.

Actual screenshots remain in the private submit-20261110 investigation and the
maintained Vipi gallery review; public captures contain only synthetic examples.
