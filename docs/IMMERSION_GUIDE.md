# Optional immersion guide

The language choice continues to a compact guide before sign-in and invitations. Both Shallow (waves) and Deep (anchor) are visible. Continue never depends on a gesture, model download, voice availability or completion state. Settings → Immersion guide reopens it without signing out or discarding the active chat/draft/invitation. The selected mode uses the existing persisted preference and carries into chat; wire enum keys remain unchanged.

The stable authored multiword source example in `data/tutorial/source-messages.json` is UI input in the selected source language. It is not a target translation catalog. Both native implementations run the normal local providers, message views, touch gestures, script/readings and speech. Captions teach gestures only once practice output exists; the audio caption additionally requires a ready voice. Failed/unsupported/preparing states stay explicit and Continue stays available.

Android keeps separate transient owners per mode so returning to Shallow restores its plan. iOS retains a transient owner across same-pair configure changes. Neither attaches a translation store/vault or references a ChatSession/account/send operation. Trying the sample never contributes learning/history. Closing, backgrounding, holding or switching stops/cancels speech. Only intentional mode/UI preference changes persist.
